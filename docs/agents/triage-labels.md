# Étiquettes de triage

Les skills raisonnent avec cinq rôles de triage canoniques. Ce fichier fait correspondre ces rôles aux étiquettes réellement utilisées dans le gestionnaire de tickets de ce dépôt.

| Rôle dans les skills | Étiquette chez nous | Signification                                     |
| -------------------- | ------------------- | ------------------------------------------------- |
| `needs-triage`       | `needs-triage`      | Un mainteneur doit évaluer ce ticket              |
| `needs-info`         | `needs-info`        | En attente d'informations de la part du demandeur |
| `ready-for-agent`    | `ready-for-agent`   | Entièrement spécifié, prêt pour un agent autonome |
| `ready-for-human`    | `ready-for-human`   | Doit être réalisé par un humain                   |
| `wontfix`            | `wontfix`           | Ne sera pas traité                                |

Quand un skill cite un rôle (par exemple « appliquer l'étiquette prêt pour agent »), utiliser l'étiquette correspondante de ce tableau.

Modifier la colonne « Étiquette chez nous » si le vocabulaire du dépôt change.
